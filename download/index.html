Every file's SHA-256 is in SHA256SUMS.txt. Windows and macOS warn about Zeno the first time, because it is not signed yet: on Windows choose “More info”, then “Run anyway”; on macOS run xattr -d com.apple.quarantine zeno.

Install from a terminal

One line. It picks the right zeno, puts it on your PATH, and offers a C compiler and git if they are missing.

On macOS and Linux.

Debian, Ubuntu, Raspberry Pi OS. apt brings a C compiler and git along if the machine has none. For a Raspberry Pi use the arm64 or armhf file.

Arch, Manjaro.

Until Zeno is in the Snap Store, a snap installed from its file needs --dangerous.

Installed for you alone.

In PowerShell, to download the setup program and run it. Or use the button above.

With Rust installed.

Each command installs version 0.3.0. What the installers do, step by step, is in the installer docs, and what each package holds in the package docs.

What Zeno needs

Nothing, to runzeno run, check, test, format and lsp are all in the one file.
A C compiler, to buildzeno build uses cc, gcc or clang. --llvm needs clang.
git, for packageszeno fetch gets packages with git. zeno build --web needs only zeno.wasm, which comes with every install.

Every version

Each release keeps all of its files. Older versions stay here for anyone who needs to match one.
