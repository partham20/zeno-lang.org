Privacy

Privacy

Zeno collects nothing about you.

The compiler and its tools

zeno sends nothing anywhere. It has no telemetry, no crash reports and no update checks. The only time it uses the network is when you ask it to: zeno fetch runs git to download the packages your zeno.package names, from the addresses written there.

The installers

The Windows setup program and install.sh download Zeno's files from GitHub, and offer to install a C compiler and git through your system's own package manager. They send nothing about you or your machine.

The playground and built pages

The playground runs your program in your browser. Nothing you write is sent to a server. A link made with “Copy link” holds the program in the part of the address after #, which browsers do not send to a server. A page made with zeno build --web uses the network only if its program calls web.fetch or web.post.

This website

zeno-lang.org is plain pages served by Cloudflare Pages. It sets no cookies and has no analytics or trackers. It loads its fonts from Google Fonts, and Cloudflare and Google may keep the usual server logs of requests, such as IP addresses. Your choice of light or dark is kept in your own browser.

Downloads

Files are downloaded from GitHub Releases, under GitHub's privacy statement.

Every journey is halfway done. Forever.

The runner has closed 0 of 1 halves

Zeno of Elea said Achilles can never catch the tortoise: first he must cover half the distance, then half of what is left, without end. It suits a compiler that will always be almost finished. The bar at the top of each page works the same way.
