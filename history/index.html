How Zeno was built

306 commits and 7 releases so far, from the first file to what is on main today.

This page lists every commit in the Zeno repository, oldest first, under the release it went into. Read from the top, it is the story of how the language was built, from an empty folder on 14 November 2026 to what is on main today.

Each line says in plain words what one commit changed. The letters and digits at its start are the commit's short name, and they open the commit on GitHub, with its full message and every line of code it touched. A release is a heading, with a few words under it on what the release brought. The last heading, Unreleased, is what is on main and in no release yet.

Two other files go with this one. The reason for every choice in the language is in docs/decisions.md, and what is still to be built is in docs/missing.md.

Zeno 0.1.0

Released 15 November 2026 · 156 commits · the release on GitHub

The first release is the largest part of the story: the whole language was built on 14 and 15 November 2026. It begins with a README and a sketch of the syntax, and then goes stage by stage. A lexer, a parser, an interpreter and a type checker come first, then a compiler to C and a garbage collector, then builds for firmware that have no collector at all, a second engine (a bytecode VM) and a second backend (LLVM). After that come the library, programs in several files, packages, a formatter, a language server for editors, and tests written in Zeno.

Most stages are three commits: the code, a walkthrough of it in docs/, and the reasons in docs/decisions.md. The release ends with The Zeno Book and with a workflow that builds zeno for ten kinds of machine. Writing the book and trying the release on a Mac and on Windows each found mistakes, and the mends are here too.

Zeno 0.2.0

Released 16 November 2026 · 19 commits · the release on GitHub

A Zeno program can be a web page, and Zeno gets installers. zeno build --web puts a program, its page and Zeno itself (built as WebAssembly) into one HTML file that a browser opens. Zeno 0.3.0

Released 16 November 2026 · 32 commits · the release on GitHub

This release is about speed. The garbage collector is rebuilt around pages and then given two generations, a program can ask for memory owned and have no collector, --release drops the overflow checks, and the VM gets faster. Six benchmarks against C, Rust and Python are added to measure all of it. Also here: sort with a function, a new playground with a real editor, and the groundwork for the package stores.

The rehearsal of the release hung on macOS, so 0.3.0 went out with the two generations on Linux only. The cause was found in 0.4.0.

Zeno 0.5.0

Released 17 November 2026 · 12 commits · the release on GitHub

Zeno writes your program in another language. zeno build --target gives the same program in JavaScript, TypeScript, Python, PHP, Go, Java, C#, C++ or Rust, as a web page, or as WebAssembly, and each prints what zeno run prints. Zeno 0.5.1

Released 17 November 2026 · 6 commits · the release on GitHub

A small release with one purpose. In 0.5.0, zeno run --vm had become a few percent slower, although no line of the VM had changed: with more code in the program, the Rust compiler had laid it out differently. 0.5.1 is 0.5.0 built as one piece, and the VM is as fast as it was in 0.4.0.

Zeno 0.5.2

Released 18 November 2026 · 41 commits · the release on GitHub

This release adds to what is around the language and leaves the language as it was. There are four more target languages (Lua, Ruby, Dart and Kotlin), and a registry, so that a package is found by its name. import python, import node and import java let a Zeno program use the libraries of those languages. zeno build --minimal writes the least C that runs a program, program.run starts another program, and the first part of the library is written in Zeno itself.

The repository moved to the zeno-src organization on GitHub. Two mistakes were mended: a float % that the C++ target got wrong, and a caught error that could stop a program built on Windows.
