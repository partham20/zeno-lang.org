A programming language

Code that reads like what it means.

Whole-word keywords, checked before it runs, small enough for a microcontroller.

readings.zeno
enum Reading {
    Value(celsius: float)
    Gap
}
for r in [Value(21.5), Gap] {
    match r {
        case Value(c) { print(f"{c} °C") }
        case Gap { print("no reading") }
    }
}
Output21.5 °C
no reading
